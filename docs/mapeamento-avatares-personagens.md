
# Mapeamento de Avatares para Nome de Personagem

## Regra de Nomenclatura Final

- Formato: nome-personagem.webp
- Padrao: ASCII, minusculo, kebab-case
- Sem espacos, sem acentos, sem caracteres especiais
- Exemplo: zeus-jovem.webp

## Politica de Renomeacao

- Renomear somente quando o personagem estiver confirmado.
- Se houver duvida, manter como `avatarN.webp` e status `pendente`.
- Preservar `legacyIndex` (ordem da galeria) para nao quebrar `avatar_index` de usuarios existentes.

## Como Preencher

1. Preencha `nome_personagem` apenas quando tiver certeza do personagem.
2. Gere `arquivo_final_sugerido` em kebab-case ASCII.
3. Troque `status` para `confirmado` quando nome estiver validado.
4. Itens `pendente` nao devem ser renomeados na Fase 3.
