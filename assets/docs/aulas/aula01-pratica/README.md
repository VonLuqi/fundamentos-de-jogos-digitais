# Aula 01 — Atividade Prática

Esta pasta serve como base para os arquivos baixados/entregues da atividade prática da Aula 01.

## Uso esperado
- armazenar a cena pré-configurada da bola física;
- guardar materiais de apoio da atividade;
- manter anotações do aluno quando necessário.

## Script base para modificar
- `controle-bola.gd` mostra um ponto de partida simples para o aluno editar.
- Os parametros principais ficam expostos no Inspector: `massa`, `gravidade_da_cena`, `friccao` e `elasticidade`.
- A ideia e testar uma alteracao por vez e observar o efeito da bola no comportamento fisico.

## Estrutura sugerida
- `cena-pratica.tscn`
- `materiais/`
- `anotacoes/`
- `controle-bola.gd`

Se a atividade for atualizada depois, mantenha esta pasta como ponto de entrada do material da aula.
