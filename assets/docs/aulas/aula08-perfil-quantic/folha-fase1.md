## Como usar na sala (Mestre)

1. Imprimir [`folha-fase1.pdf`](./folha-fase1.pdf) **frente+verso** — **uma cópia por aluno** (~25 min).
2. Frente = perfil/listas; verso = mapa em grade (folha inteira).
3. Só depois: Godot (`Camera2D` + montar o esboço no `cenario.tscn`).
4. Em dupla: podem alinhar o mesmo layout, mas **cada um preenche a própria folha**.
