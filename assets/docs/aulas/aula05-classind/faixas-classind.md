# Tabela didática — Faixas ClassInd (Aula 05)

> Uso em sala: **leitura operacional**, não decorar legislação.  
> Valores alinhados ao copy de `pages/aula5.html` e aos slides da aula.

## Escala

| Faixa | Leitura operacional |
| :---: | :--- |
| **L** (Livre) | Adequado a todas as idades; violência inexistente ou muito fantasiosa/cômica |
| **10** | Violência leve / fantasiosa; medo leve; linguagem ocasional sem carga sexual |
| **12** | Violência mais presente (sem extremo); temas sexuais insinuados; linguagem mais pesada |
| **14** | Violência mais intensa; sexualidade mais explícita em tom; drogas em menção / contexto |
| **16** | Violência forte; conteúdo sexual / drogas com destaque; horror mais visceral |
| **18** | Violência extrema / gore; sexo explícito; drogas com glamourização ou uso detalhado |

## Eixos × exemplos de feedback

| Eixo | Empurra faixa **para baixo** | Empurra faixa **para cima** |
| :--- | :--- | :--- |
| **Violência** | Slimes, robôs, partículas de luz, comicidade | Sangue arterial, desmembramento, cadáveres humanos |
| **Sexo** | Afeto sem nudez / sem recompensa sexual | Nudez, atos explícitos, opção sexual como prêmio |
| **Drogas** | Poção / bateria mágica / “energia” | Seringa realista, glamourização, uso detalhado |

## Atenuantes e agravantes (resumo)

| Atenuantes | Agravantes |
| :--- | :--- |
| Fantasia, não-humano, comicidade | Realismo, gore, cadáveres |
| Sem sangue / sem foco em sofrimento | Tortura, nudez, glamourização de substâncias |
| Cura simbólica | Drogas realistas como mecânica de cura |

## Exemplos de “mesmo loop, faixa diferente”

| Loop-core | Feedback “pesado” | Feedback higienizado | Mira típica |
| :--- | :--- | :--- | :--- |
| Eliminar ameaça → recuperar recurso | Desmembramento + seringas | Robôs de sucata + baterias mágicas | L / 10 |
| Combate corpo a corpo | Sangue e cadáveres | Energia estilizada / inimigos slime | 10 / 12 |
| Dating / relacionamentos | Opções sexuais explícitas | Afeto e diálogo sem nudez | L / 10 |
| Sobrevivência com medo | Substâncias realistas para “aguentar” | Amuleto / respiração / luz ritual | 10 / 12 |
